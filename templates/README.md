# DOCX Resume Template

This directory contains a clean, professional Microsoft Word (`.docx`) resume template.

## How to Use

If you prefer using Microsoft Word or Google Docs over LaTeX, you can use the template provided here:

1. Download the `FirstName_LastName_Resume.docx` file.
2. Open it in Microsoft Word or Google Docs.
3. Replace the placeholder text with your actual details.
4. Make sure to adhere to the content and formatting guidelines outlined in the [Resume Guide](../docs/resume-guide.md).
5. **Always export or "Save As" a PDF before submitting your resume!**

> [!WARNING]
> Do not change the margins or layout styles drastically, as the template is already formatted to be single-column and ATS-friendly. Keep your resume strictly to one page!
